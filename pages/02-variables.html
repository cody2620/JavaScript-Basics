변수란 무엇일까요?

변수는 데이터를 담는 상자입니다. 상자에 이름을 붙여서 나중에 필요할 때 꺼내 쓸 수 있습니다.

예를 들어, 선물을 보관하는 상자라고 생각해보세요:

📦 myBox ← 이름
   ↓
  ["iPhone"] ← 안에 들어있는 값

let과 const 사용하기

1. let — 값이 변할 수 있는 변수

let은 나중에 값을 바꿀 수 있는 변수를 만듭니다.

// 변수 선언하고 값 할당
let age = 20;
console.log(age);    // 20

// 나중에 값을 바꿀 수 있음
age = 21;
console.log(age);    // 21
let name = "철수";
console.log(name);    // 철수

name = "영희";
console.log(name);    // 영희

2. const — 값이 바뀌지 않는 상수

const는 한 번 정하면 바꿀 수 없는 상수입니다. 대부분의 변수는 const로 만드세요.

// 상수 선언
const PI = 3.14159;
console.log(PI);      // 3.14159

// 이렇게 하면 에러!
PI = 3.14;            // ❌ TypeError: Assignment to constant variable
const country = "대한민국";
console.log(country);  // 대한민국

// 다시 할당하려고 하면 에러 발생
// country = "일본";   // 이 줄의 주석을 제거하면 에러가 발생합니다

3. var — 예전 방식 (사용하지 않기)

var는 예전 JavaScript에서 사용했던 방식입니다. 요즘은 let, const를 사용합니다.

좋은 변수 이름 짓기

// ✅ 좋은 이름
let userName = "철수";
let isActive = true;
let totalPrice = 50000;

// ❌ 나쁜 이름
let x = "철수";
let 1name = "철수";  // 숫자로 시작하면 안됨
let user-name = "철수";  // 하이픈 사용 금지

변수 이름 규칙:

  • 문자, 숫자, _, $ 만 사용
  • 숫자로 시작하면 안 됨
  • 띄어쓰기 금지
  • 의미 있는 이름 사용
  • 낙타 표기법 추천: userName (첫 단어는 소문자, 다음 단어 첫글자는 대문자)

변수의 범위(스코프)

변수는 선언된 위치에 따라 사용할 수 있는 범위가 달라집니다.

// 전역 변수 (어디서나 사용 가능)
let globalVar = "전역";

{
  // 블록 변수 (이 { } 안에서만 사용 가능)
  let blockVar = "블록";
  console.log(globalVar);  // ✅ 가능
  console.log(blockVar);   // ✅ 가능
}

console.log(globalVar);  // ✅ 가능
console.log(blockVar);   // ❌ ReferenceError
let x = 10;  // 전역 변수

{
  let x = 20;  // 블록 변수 (다른 x)
  console.log(x);  // 20
}

console.log(x);  // 10

자주 하는 실수

⚠️ 실수 1: 같은 이름으로 두 번 선언하기

let name = "철수";
let name = "영희";  // ❌ 에러! 이미 선언된 변수

해결: 새로 선언하지 말고 값을 할당하세요.

let name = "철수";
name = "영희";  // ✅ 맞음

⚠️ 실수 2: const에 다시 값을 할당하기

const age = 20;
age = 21;  // ❌ 에러!

해결: 값이 변해야 한다면 let을 사용하세요.

let age = 20;
age = 21;  // ✅ 맞음

⚠️ 실수 3: 선언 없이 변수 사용하기

console.log(score);  // ❌ 에러! 선언되지 않은 변수

해결: 항상 let이나 const로 선언하세요.

let score = 100;
console.log(score);  // ✅ 맞음

문제 2: let과 const 구분하기

다음 중 const를 사용해야 하는 것은 어느 것일까요?

A) 사용자의 나이 (시간이 지나면 바뀜)
B) 원주율 π (절대 바뀌지 않음)
C) 게임의 점수 (게임 중 올라감)

💡 정답 보기

정답: B) 원주율 π

절대 변하지 않는 값은 const를 사용합니다.

const PI = 3.14159;  // ✅
let age = 20;        // ✅
let score = 0;       // ✅
