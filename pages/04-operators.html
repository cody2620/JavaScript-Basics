연산자

값을 계산하고 비교하고 판단하는 방법을 배웁니다.

📚 학습 목표

  • 산술 연산자로 계산하기
  • 비교 연산자로 값 비교하기 (== vs ===)
  • 논리 연산자로 조건 판단하기
  • 삼항 연산자와 널 병합 연산자 사용하기

산술 연산자 (Arithmetic Operators)

숫자를 계산할 때 사용합니다.

연산자 설명 예
+ 더하기 5 + 3 = 8
- 빼기 5 - 3 = 2
* 곱하기 5 * 3 = 15
/ 나누기 6 / 2 = 3
% 나머지 5 % 2 = 1
** 거듭제곱 2 ** 3 = 8 
console.log(10 + 5);   // 15
console.log(10 - 5);   // 5
console.log(10 * 5);   // 50
console.log(10 / 5);   // 2
console.log(10 % 3);   // 1
console.log(2 ** 3);   // 8

단축 연산자 (Shorthand)

자주 쓰이는 계산을 더 짧게 쓸 수 있습니다.

let x = 10;

x += 5;   // x = x + 5;  → 15
x -= 3;   // x = x - 3;  → 12
x *= 2;   // x = x * 2;  → 24
x /= 4;   // x = x / 4;  → 6

x++;      // x = x + 1;  → 7
x--;      // x = x - 1;  → 6
let count = 10;
console.log(count);      // 10

count += 5;
console.log(count);      // 15

count--;
console.log(count);      // 14

비교 연산자 (Comparison Operators)

두 값을 비교해서 참(true) 또는 거짓(false)을 반환합니다.

연산자 의미 예
== 같다 (값만 비교) 5 == "5" → true
=== 같다 (값과 타입 모두) 5 === "5" → false
!= 다르다 (값만 비교) 5 != "5" → false
!== 다르다 (값과 타입 모두) 5 !== "5" → true
< 보다 작다 3 < 5 → true
> 보다 크다 3 > 5 → false
<= 작거나 같다 5 <= 5 → true
>= 크거나 같다 5 >= 5 → true

== vs === 의 중요한 차이!

console.log(5 == "5");      // true  (값이 같음)
console.log(5 === "5");     // false (타입이 다름)

console.log(0 == false);    // true
console.log(0 === false);   // false

// ✅ 권장: 항상 ===를 사용하세요!
console.log(10 === 10);     // true

논리 연산자 (Logical Operators)

여러 조건을 합칠 때 사용합니다.

1. && (그리고 - AND)

모든 조건이 참일 때만 참을 반환합니다.

console.log(true && true);     // true
console.log(true && false);    // false
console.log(false && false);   // false

// 실제 예
let age = 20;
let hasLicense = true;
console.log(age >= 18 && hasLicense);  // true (둘 다 만족)

2. || (또는 - OR)

하나라도 참이면 참을 반환합니다.

console.log(true || false);    // true
console.log(false || false);   // false
console.log(false || true);    // true

// 실제 예
let isWeekend = false;
let isHoliday = true;
console.log(isWeekend || isHoliday);  // true (하나라도 만족)

3. ! (아니다 - NOT)

참/거짓을 반대로 바꿉니다.

console.log(!true);    // false
console.log(!false);   // true

let isLoggedIn = true;
console.log(!isLoggedIn);  // false

삼항 연산자 (Ternary Operator)

조건에 따라 다른 값을 선택하는 간단한 방법입니다.

조건 ? 참일때 : 거짓일때

let age = 20;
let status = age >= 18 ? "성인" : "미성년자";
console.log(status);  // "성인"
let score = 85;
let grade = score >= 90 ? "A" : score >= 80 ? "B" : "C";
console.log(grade);  // B

let name = "철수";
console.log(name === "철수" ? "맞습니다!" : "다릅니다");

널 병합 연산자 (??)

값이 null 또는 undefined일 때만 기본값을 사용합니다.

let color = null;
let defaultColor = color ?? "파란색";
console.log(defaultColor);  // "파란색"

let name = "철수";
let displayName = name ?? "손님";
console.log(displayName);   // "철수"
let userAge = null;
console.log(userAge ?? 0);  // 0 (null이므로 0 사용)

let productPrice = 5000;
console.log(productPrice ?? 0);  // 5000 (값이 있으므로 그대로)

연산자 우선순위

계산 순서는 수학의 법칙을 따릅니다.

// 1단계: ()
// 2단계: **, *, /, %
// 3단계: +, -
// 4단계: <, >, <=, >=
// 5단계: ==, ===, !=, !==
// 6단계: &&
// 7단계: ||

console.log(2 + 3 * 4);      // 14 (3*4를 먼저 계산)
console.log((2 + 3) * 4);    // 20 (2+3을 먼저 계산)

자주 하는 실수

⚠️ 실수 1: == 와 === 구분 안 하기

5 == "5"   // true (위험함!)
5 === "5"  // false (안전함) ✅

// 항상 === 를 사용하세요!

⚠️ 실수 2: = 와 == 헷갈리기

let x = 5;     // 할당
if (x == 5) {} // 비교 (맞음)
if (x = 5) {}  // 할당! (이건 위험)

⚠️ 실수 3: && 와 || 우선순위

// && 가 || 보다 먼저 계산됨
true || false && false  // true
(true || false) && false // false (다른 결과!)
// 명확하게 괄호를 사용하세요!
