자바스크립트 소개

자바스크립트가 무엇이고, 어디서 어떻게 실행하는지 알아봅니다.

자바스크립트는 무엇일까요?

자바스크립트(JavaScript)는 웹 브라우저에서 실행되는 프로그래밍 언어입니다. 웹 페이지를 동작하게 만드는 거의 모든 상호작용이 자바스크립트로 작성되어 있습니다.

📌 주요 특징

  • 동적 페이지 — 페이지를 새로 고침 없이 내용을 바꿀 수 있습니다.
  • 사용자 상호작용 — 사용자의 클릭, 입력 등에 반응합니다.
  • 브라우저 기반 — 설치할 필요가 없고 모든 브라우저에서 실행됩니다.
  • 서버 언어 — 최신에는 Node.js로 서버에서도 실행됩니다.

자바스크립트의 간단한 예

다음은 버튼을 클릭하면 알림 상자를 띄우는 예제입니다:

// 버튼 요소를 찾고 클릭 이벤트를 등록합니다.
document.getElementById('myButton').addEventListener('click', function() {
    alert('안녕하세요!');
});

자바스크립트를 실행하는 방법

1. 브라우저의 콘솔

모든 브라우저에는 개발자 도구라는 기능이 있습니다. 다음 단계로 콘솔을 열어보세요:

  1. 브라우저에서 F12 또는 우클릭 → 검사를 누릅니다.
  2. Console(콘솔) 탭을 선택합니다.
  3. 다음을 입력하고 Enter를 누릅니다:
console.log('Hello, JavaScript!');

콘솔에 Hello, JavaScript!가 출력됩니다.

2. HTML 파일에 포함

HTML 파일의 <script> 태그 안에 자바스크립트 코드를 작성할 수 있습니다:

<html>
<head>
    <title>나의 첫 페이지</title>
</head>
<body>
    <h1>안녕하세요</h1>

    <script>
        console.log('이 코드가 실행됩니다!');
    </script>
</body>
</html>

3. 외부 자바스크립트 파일

자바스크립트 코드를 별도의 .js 파일로 저장하고 HTML에서 불러올 수 있습니다:

<script src="script.js"></script>

다음은 무엇을 배울까요?

다음 단원에서는 변수와 상수를 배웁니다. 변수는 자바스크립트의 가장 기본적인 개념으로, 값을 저장하고 사용하는 방법을 알려줍니다.

💪 실습

지금 바로 브라우저 콘솔을 열어서 다음을 입력해보세요:

console.log('안녕');
console.log(123);
console.log(true);
