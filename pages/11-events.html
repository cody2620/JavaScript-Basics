이벤트란?

이벤트는 사용자가 하는 동작입니다. 클릭, 입력, 키 누르기, 마우스 이동 등이 있습니다.

사용자 → 클릭 → 이벤트 발생 → 코드 실행

addEventListener — 이벤트 등록하기

가장 일반적인 이벤트 등록 방식입니다.

  // 이벤트 발생 시 실행할 코드
});

// list.children[2].addEventListener("click", handler);

실제 예제: 입력 검증

💡 예제: 이메일 검증

// HTML
// <input id="email" type="text" placeholder="이메일 입력">
// <p id="message"></p>

// JavaScript
let emailInput = document.getElementById("email");
let message = document.getElementById("message");

emailInput.addEventListener("input", function() {
  let email = emailInput.value;

  // 간단한 이메일 검증
  if (email.includes("@") && email.includes(".")) {
    message.textContent = "✅ 유효한 이메일입니다";
    message.style.color = "green";
  } else {
    message.textContent = "❌ 유효하지 않은 이메일입니다";
    message.style.color = "red";
  }
});

on속성 vs addEventListener

on속성 (구식):

element.onclick = function() { ... };
element.onmouseover = function() { ... };

addEventListener (현대식, 권장):

element.addEventListener("click", function() { ... });
element.addEventListener("mouseover", function() { ... });

차이:

  • addEventListener는 여러 번 등록 가능 (on속성은 덮어씀)
  • addEventListener는 제거 가능 (removeEventListener)
  • addEventListener는 이벤트 흐름 제어 가능

자주 하는 실수

⚠️ 실수 1: 함수 호출 괄호 붙임

// ❌ 이렇게 하면 페이지 로드 시 즉시 실행됨
button.addEventListener("click", sayHello());

// ✅ 함수 자체를 전달
button.addEventListener("click", sayHello);

// ✅ 또는 익명 함수 사용
button.addEventListener("click", function() {
  sayHello();
});

⚠️ 실수 2: this의 의미 모르기

let button = document.getElementById("btn");
button.addEventListener("click", function() {
  console.log(this);  // button 요소 (이벤트를 받은 요소)
});

⚠️ 실수 3: 이벤트 객체 무시하기

// 정보가 필요할 수 있으니 항상 event 객체를 받자
form.addEventListener("submit", function(event) {
  event.preventDefault();  // 폼 제출 막기
});
