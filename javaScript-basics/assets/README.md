# JavaScript 기초 - 완전 초보자 가이드

🎓 **프로젝트 소개**

완전 초보자를 위한 무료 JavaScript 입문 튜토리얼입니다. 브라우저만으로 바로 시작할 수 있으며, 각 단원마다 직접 코드를 작성하고 실행해볼 수 있습니다.

## 📚 학습 내용 (11개 단원)

1. **자바스크립트 소개** - 자바스크립트가 무엇이고 어디서 실행하는지
2. **변수와 상수** - let, const, var의 차이와 올바른 사용법
3. **자료형** - 숫자, 문자, 불리언, null, undefined
4. **연산자** - 산술, 비교(== vs ===), 논리, 삼항, 널 병합 연산자
5. **조건문** - if/else/else if, switch 문
6. **반복문** - for, while, do...while, for...of, break/continue
7. **함수** - 선언식, 표현식, 화살표 함수, 매개변수, 반환값
8. **배열** - 배열 메서드, map/filter/reduce, forEach
9. **객체** - 속성, 메서드, 구조 분해, JSON
10. **DOM 조작** - 요소 선택, 내용/스타일 변경, 요소 생성/삭제
11. **이벤트** - addEventListener, 이벤트 종류, preventDefault

## ✨ 주요 기능

- 🎯 **Try it 에디터** - 코드를 직접 수정하고 실행 가능
- ⚡ **실시간 피드백** - console.log 결과를 즉시 표시
- ❌ **에러 표시** - 코드 오류를 읽기 쉽게 출력
- 🌙 **다크/라이트 모드** - 테마 선택 (localStorage 저장)
- 📱 **반응형 디자인** - 모바일/태블릿/데스크톱 모두 지원
- 📖 **접근성** - 키보드 네비게이션, 스크린리더 지원
- 📝 **연습 문제** - 각 단원마다 2~3개 연습 문제 + 토글식 정답

## 🎯 학습 방법

1. **[홈페이지](http://localhost:8000)에서 시작하기** 클릭
2. **왼쪽 사이드바**에서 현재 강의 확인
3. **개념 설명** 읽기
4. **Try it 에디터**에서 코드 실행해보기
5. **코드 수정**해서 결과 확인
6. **연습 문제** 풀기 (정답은 토글로 확인)
7. **다음 단원** 버튼으로 이동
