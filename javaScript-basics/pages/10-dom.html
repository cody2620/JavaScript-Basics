DOM이란?

DOM(Document Object Model)은 HTML을 트리 구조로 나타낸 것입니다. JavaScript로 이 트리를 조작해서 웹 페이지를 동적으로 변경합니다.

document → HTML 문서
├── head
└── body
    ├── h1
    ├── p
    └── div

요소 선택하기

1. getElementById — ID로 선택

document.getElementById("아이디")
// HTML: <p id="demo">안녕하세요</p>
// 실제로는 아래 코드가 실행됨 (데모용)

let element = {textContent: "안녕하세요"};  // 시뮬레이션
console.log(element.textContent);  // 안녕하세요

클래스 추가/제거하기

CSS 클래스를 사용하면 스타일을 더 쉽게 관리할 수 있습니다.

add — 클래스 추가

element.classList.add("클래스명");

remove — 클래스 제거

element.classList.remove("클래스명");

toggle — 클래스 전환

element.classList.toggle("클래스명");  // 있으면 제거, 없으면 추가
// 시뮬레이션용 객체
let element = {
  classList: {
    classes: []
  }
};

// 클래스 추가
element.classList.classes.push("active");
console.log("active 클래스 추가됨");

실제 예제: 할일 목록

💡 코드 예제

// HTML
// <input id="taskInput" type="text">
// <button id="addBtn">추가</button>
// <ul id="taskList"></ul>

// JavaScript
let taskInput = document.getElementById("taskInput");
let addBtn = document.getElementById("addBtn");
let taskList = document.getElementById("taskList");

addBtn.addEventListener("click", function() {
  if (taskInput.value === "") return;

  // 새 리스트 아이템 만들기
  let li = document.createElement("li");
  li.textContent = taskInput.value;

  // 목록에 추가
  taskList.appendChild(li);

  // 입력창 비우기
  taskInput.value = "";
});

DOM 메서드 비교

메서드 설명

textContent 순수 텍스트만 변경
innerHTML HTML 포함해서 변경
style CSS 스타일 직접 변경

자주 하는 실수

⚠️ 실수 1: null 확인 안 하기

// 요소가 없으면 null 반환
let element = document.getElementById("missing");
element.textContent = "텍스트";  // ❌ 에러! null이므로 속성 접근 불가

해결: 먼저 확인하세요.

let element = document.getElementById("missing");
if (element) {
  element.textContent = "텍스트";  // ✅
}

⚠️ 실수 2: innerHTML로 사용자 입력 받기

// ❌ 위험! XSS 취약점
let userInput = "<img src=x onerror='alert(1)'>";
element.innerHTML = userInput;  // 공격 코드 실행!

해결: 신뢰할 수 없는 데이터는 textContent 사용.

element.textContent = userInput;  // ✅ 안전

⚠️ 실수 3: CSS 속성명을 CSS 형식으로 쓰기

element.style.background-color = "blue";  // ❌ 작동 안 함
element.style.backgroundColor = "blue";   // ✅ camelCase 사용
