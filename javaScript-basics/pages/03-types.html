자료형이란?

자료형은 데이터의 종류입니다. 숫자는 숫자, 문자는 문자, 참/거짓은 참/거짓으로 구분합니다.

5          ← 숫자(Number)
"hello"    ← 문자(String)
true       ← 참/거짓(Boolean)

기본 자료형 5가지

1. 숫자 (Number)

정수와 소수를 포함한 모든 숫자입니다.

let age = 20;
let price = 19.99;
let temperature = -5;

console.log(age);
console.log(price);
console.log(temperature);

특수한 숫자값:

Infinity   ← 무한대
-Infinity  ← 음의 무한대
NaN        ← Not a Number (숫자가 아님)
console.log(10 / 0);          // Infinity
console.log("hello" * 2);     // NaN (문자를 숫자로 계산할 수 없음)

2. 문자열 (String)

큰따옴표(") 또는 작은따옴표(')로 감싼 텍스트입니다.

let name = "철수";
let greeting = '안녕하세요';
let emoji = "🎉";

console.log(name);
console.log(greeting);
console.log(emoji);

문자열 안에 따옴표 포함하기:

let sentence = "He said \"Hello\"";    // \" 이스케이프
let message = 'It\'s nice';              // \' 이스케이프
let path = "C:\\Users\\name";            // \\ = \
console.log("He said \"Hello\"");
console.log('It\'s nice');
console.log("Hello\nWorld");  // \n = 줄바꿈

3. 불리언 (Boolean)

참(true) 또는 거짓(false) 중 하나입니다.

let isStudent = true;
let hasLicense = false;

console.log(isStudent);
console.log(hasLicense);

4. null과 undefined

null은 "값이 없음"을 의도적으로 표현합니다.
undefined는 선언되었지만 아직 값이 할당되지 않았습니다.

let x = null;        // 의도적으로 값이 없음
let y;               // 선언만 함
let z = undefined;   // 명시적으로 undefined

console.log(x);  // null
console.log(y);  // undefined
console.log(z);  // undefined

typeof 연산자 — 자료형 확인하기

변수가 무슨 자료형인지 확인할 때 typeof를 사용합니다.

console.log(typeof 42);        // "number"
console.log(typeof "hello");   // "string"
console.log(typeof true);      // "boolean"
console.log(typeof undefined); // "undefined"
console.log(typeof null);      // "object" (이건 버그!)
console.log(typeof {});        // "object"

자료형 변환

문자열로 변환하기

String(123)      // "123"
String(true)     // "true"
(123).toString() // "123"
let num = 42;
let str = String(num);
console.log(str);       // "42"
console.log(typeof str); // "string"

숫자로 변환하기

Number("123")    // 123
Number("3.14")   // 3.14
Number(true)     // 1
Number(false)    // 0
Number(null)     // 0
parseInt("123")  // 123 (정수만)
console.log(Number("456"));      // 456
console.log(Number("3.14"));     // 3.14
console.log(Number("hello"));    // NaN (변환 실패)
console.log(parseInt("789abc")); // 789 (숫자 부분만)

불리언으로 변환하기

Boolean(1)       // true
Boolean(0)       // false
Boolean("")      // false (빈 문자열)
Boolean("text")  // true
Boolean(null)    // false
Boolean(undefined) // false
console.log(Boolean(1));       // true
console.log(Boolean(0));       // false
console.log(Boolean(""));      // false
console.log(Boolean("hello")); // true

템플릿 리터럴 (Template Literal)

백틱(`)을 사용하면 문자열에 변수를 쉽게 포함할 수 있습니다. ${변수} 형식을 사용합니다.

let name = "철수";
let age = 20;

// 예전 방식
let msg1 = name + "은 " + age + "살입니다";

// 템플릿 리터럴 (더 간단!)
let msg2 = `${name}은 ${age}살입니다`;

console.log(msg1);  // 철수은 20살입니다
console.log(msg2);  // 철수은 20살입니다
let fruit = "딸기";
let quantity = 10;

// 템플릿 리터럴
console.log(`${fruit}를 ${quantity}개 샀습니다`);

// 계산도 가능
let a = 5;
let b = 3;
console.log(`${a} + ${b} = ${a + b}`);

자주 하는 실수

⚠️ 실수 1: 따옴표 빠뜨리기

console.log(hello);  // ❌ 에러! hello는 변수로 인식
console.log("hello"); // ✅ 맞음

⚠️ 실수 2: 숫자와 문자열 구분 못하기

console.log(typeof "42");  // "string"
console.log(typeof 42);    // "number"

"42" + 8      // "428" (문자열 결합)
42 + 8        // 50 (숫자 덧셈)

⚠️ 실수 3: null과 undefined 혼동

// null: 의도적으로 "값 없음"을 표현
let person = null;

// undefined: 값이 아직 할당되지 않음
let age;

typeof null       // "object" (이상하지만 이렇게 정의됨)
typeof undefined  // "undefined"

문제 2: 자료형 변환하기

문자열 "100"을 숫자로 변환하고, 이를 50과 더한 결과를 출력하세요.

// 여기에 코드를 작성하세요
let str = "100";
// Number()를 사용해서 변환하고 50과 더하기
console.log(/* 여기에 코드 */);  // 150이 출력되어야 함
💡 정답 보기 
let str = "100";
console.log(Number(str) + 50);  // 150

문제 3: 템플릿 리터럴 사용하기

"코딩은 초급 강의입니다"라는 문장을 템플릿 리터럴로 만들어 출력하세요.

// 여기에 코드를 작성하세요
let title = "코딩";
let level = "초급";
console.log(/* 템플릿 리터럴 */);
